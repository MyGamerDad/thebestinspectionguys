# The Best Inspection Guys | Coming Soon Website

A self-contained responsive landing page for GitHub Pages. It uses the supplied original logo, blue and green brand colors, and the property artwork from the approved concept.

## What is included

* `index.html`: page content, navigation, services and clickable contact links
* `styles.css`: desktop, tablet and mobile responsive design
* `script.js`: mobile navigation and automatic copyright year
* `assets/logo.webp`: brand image, cropped from the supplied logo
* `assets/property-hero.webp`: hero imagery cropped from the approved mockup
* `assets/favicon.png`: browser tab icon
* `assets/social-preview.webp`: social sharing image
* `.nojekyll`: prevents GitHub Pages from altering the static files

There are no build steps, dependencies, trackers, contact forms or external fonts. The contact links open the visitor's telephone dialer or email application.

## Publish using GitHub Pages

1. Open GitHub and create a **Public** repository, for example `the-best-inspection-guys`.
2. Open the repository and choose **Add file → Upload files**. Unzip the download first, then upload the *contents* of this package to the repository root, preserving the `assets` folder. Commit the files.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**. Choose branch `main`, folder `/(root)` and **Save**.
5. Once Pages has published, the URL will generally be `https://YOUR-USERNAME.github.io/the-best-inspection-guys/`. Check the exact URL shown under Settings → Pages.

**Important:** The `index.html` file must be at the repository root, not in an extra outer folder. Do not set a custom domain unless you own the domain and configure its DNS correctly. If you later want a custom domain, follow GitHub's Pages custom domain instructions.

## Preview on your computer

Open `index.html` in a web browser. For a closer production preview, serve the directory locally with `python -m http.server 8000` and visit `http://localhost:8000`.
